# V2.1 implementation audit

Baseline: existing monthly `run_backtest` multiplies external contributions, executes at
signal close, computes drawdown on a contributed asset balance, and annualizes final
value / total deposits. It has no cash ledger, initial holdings, queue, execution venue,
cycle state, fixed tactical budget, rolling cohorts or event study. `data.py` attaches
current trailing PE to historical rows. Existing templates remain a legacy exploratory
workflow, explicitly labelled; they must not be used as V2.1 evidence.

V2.1 extends the existing Python package and Streamlit entry point. The account engine
uses explicit initial cash, bonds, units and an independently checked total. Bonds are
constant-value reserves (no automatic sale); orders may spend only cash above the
cash+bonds reserve floor. All amounts are CNY; asset price columns are CNY adjusted
prices / explicitly documented total-return proxies. NDX is a separate USD unadjusted
price signal. Orders execute at a later dated observed close, never at signal close.
This conservative next-close convention is not next-open or guaranteed broker fill.
Actual QDII requires a separately supplied dated NAV / executable-price series, inception,
fees and daily caps; no active fund is backfilled with QQQ. Cross-market NAV publication
and subscription calendars must be encoded by supplied eligible dates; automatic broker
calendar/NAV confirmation reconciliation is not implemented.

## Verification and scope

81 tests pass, including 30 new parametrized cases, archived-data UI interaction,
future-prefix invariance (A–E and F vintage updates), independent ledger tampering,
fees/premium/caps, missing sessions, tactical budget exhaustion and holdout freeze.
The report independently reconciles 30 real-history strategy/window accounts.
See `reports/test-results.txt`, `ledger-audit.json`, `run-config.json`, and
`environment.json`. Source and normalized snapshot hashes are checked on load.

Actual initial holdings are valued at the last observed pre-start marks; daily
allocation sizes use previous known marks. Ordinary deposits are predetermined,
not multiplied by a strategy signal. All reported cohorts use identical schedules.
Rolling optimization slices one longest run per start; tests compare its prefixes
against independently run shorter accounts.

Implemented first-layer real-history evidence covers QQQ from 2000 and the three
real ETFs from June 2020. Second-layer policy experiments accept actual product
prices, dated caps/fees, inception, missing execution dates and premiums. Complete
historical execution of the two active QDII replacements has **not** been verified:
no authenticated historical limit/NAV-confirmation calendars were obtained. The
engine uses conservative later-session closes and does not implement a broker's
cash-reservation / pending-NAV-confirmation lifecycle. Thus the archived report is
not a real-QDII performance claim. Strategy F is unavailable without vintage data;
its model, sensitivity and strict frozen-holdout entry point are implemented/tested.

Remaining research: product-specific timestamp adapters and confirmed historical
execution feeds; licensed historical forward earnings/PE; pre-registered out-of-sample
valuation experiments. The default nine-month strategy is implemented; a separately
funded perpetual tactical-cash control is not enabled by default.
